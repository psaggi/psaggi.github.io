# psaggi.github.io

Jekyll source for Piyush Saggi's personal site.

## Publishing a new experiment
Add a Markdown file to `_experiments/` with front matter containing `title`, `date`, `eyebrow`, and `description`. GitHub Pages rebuilds automatically after commit. The homepage shows the three newest experiments; `/experiments/` shows all experiments.

## Publishing writing
Add a Markdown file to `_writing/` with `title`, `date`, `category`, and `description`. The homepage shows the three newest entries; `/writing/` shows all writing.

Do not add `.nojekyll`; this version intentionally uses Jekyll.
